Improvement
What is it
  • Difference (percentage points) between a Local model and the best comparable base model.
  • Only applies to Local rows; others show "-".
Calculation
  • Each Local result is compared to the best accuracy of models with the same model_base, same iterations and same cuts, but non-Local discretization.
  • Improvement = (accuracy_local - best_base_accuracy) x 100.
  • best_base_model and best_base_accuracy come from precomputed data in results.json.
Usage
  • Positive values: Local outperforms the best base in that scenario.
  • Negative values: the best base is superior to Local.
