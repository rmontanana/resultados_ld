Ollama not available online

Ollama is an AI server that runs on your computer. To use it with this page, you need to run it locally.

1 Install Ollama

Download and install from ollama.ai

2 Download this page
git clone https://github.com/rmontanana/resultados_ld.git
3 Start a local server
cd resultados_ld && python -m http.server 8000

Alternatives: npx serve o php -S localhost:8000

4 Start Ollama with a model
ollama run llama3.2
5 Open the local page

Visit http://localhost:8000/ai-chat.html

Alternative without installation: Use the "Copy context" mode to paste directly in claude.ai, chatgpt.com or gemini.google.com
